Connect Google Sheet

Follow these steps once to connect your Google Sheet. After setup, all edits sync live across everyone who opens this file.

1
Go to sheets.google.com and create a new blank spreadsheet. Name it Advocus M&A Directory.
2
In the spreadsheet, click Extensions → Apps Script. Delete any existing code and paste in the Apps Script code from the google-apps-script.js file provided alongside this HTML file.
3
In Apps Script, click Deploy → New deployment. Set type to Web app, set "Execute as" to Me, set "Who has access" to Anyone. Click Deploy and copy the Web app URL.
4
Paste the Web app URL below and click Save. The dashboard will sync all data to your Sheet automatically.

This URL is saved in your browser. Each person using the dashboard needs to enter it once.
